# AI味违禁词库与过检替换对照表 (AI Smell Banned Tokens & Grammar Anti-Patterns)

本表汇整了腾讯朱雀算法、主流 AIGC 检测器的高频特征词，以及 [Humanizer-zh](https://github.com/op7418/Humanizer-zh) 提炼的中文表达病理。在改写公众号文章时，以下词汇与句式一律列入**高危红线名单**。

## 1. 结构与转折套话（红线词库）

| AI 高频滥用套话 | 人味化/过检替换方案 | 语法说明 |
| :--- | :--- | :--- |
| **不可否认的是 / 毋庸置疑** | 说白了 / 谁都清楚 / 摆在明面上的事实是 | 口语化降维，击碎机械感 |
| **值得注意的是 / 引人注目的是** | 但有意思的是 / 可你往深里一抠 / 诡异的地方来了 | 制造情绪钩子与好奇心 |
| **显而易见 / 众所周知** | 明眼人一眼看穿 / 稍微懂点行情的都知道 | 代入具体市井视角 |
| **这不仅是……更是……（假递进）** | 拆成短句：“这不是XXX。这是赤裸裸的YYY。” | 破除典型AI并列递进长句 |
| **不是……而是……（假对比）** | 删去否定项，直接陈述事实本身 | 破除无信息增量的铺垫 |
| **总而言之 / 综上所述 / 简而言之** | 彻底删掉，直接切入最后一句结论或疑问 | 真实人类写作绝不使用报告型总结词 |
| **令人扼腕叹息 / 令人唏嘘不已** | 惨。/ 听得人后颈窝发凉。/ 一声长叹。 | 用短促的生理反应代替文学空洞概括 |
| **展现得淋漓尽致 / 深刻地体现** | 算盘打得震天响 / 扒得连底裤都不剩 | 俚俗但精准的具象动态表达 |
| **在历史的长河中 / 岁月如梭** | 彻底删除！直接以场景、具体时间或动作开场 | 废除宏大叙事虚词 |
| **让我们深入探讨 / 以下是你需要知道的** | 彻底删除！前句悬念直接撞向下句事实 | 消除“清痰式”起跑铺垫 |
| **不要误会，我并不是在……** | 彻底删除！直接陈述客观论据与限制条件 | 消除无对象的自我辩解 |
| **充分彰显了……的不懈追求** | 彻底删除！删除句尾的马屁式拔高 | 消除无实质价值的赞美 |

## 2. 中文本土化句式病理整改（吸收 Humanizer-zh）

### ❌ 1. “进行＋动词”病句（公文机器腔）
- **AI 典型病句**：“对叛将进行了痛骂”、“对数据进行全面优化”、“对敌军进行围剿”。
- **人味化整改**：中文动词天然可作谓语，直接删除“进行”——“痛骂叛将”、“全面优化数据”、“围剿敌军”。

### ❌ 2. 层叠的长定语（“的”字连环套）
- **AI 典型病句**：“这是一个关于司马迁受宫刑背后的极其残酷的人性博弈的故事”。
- **人味化整改**：化解多重定语，拆为长短错落的主干句：“司马迁受宫刑，背后是一场惨绝人寰的人性博弈。”

### ❌ 3. 滥用“被字句”与欧化语法
- **AI 典型病句**：“李陵被匈奴所围困，尊严被彻底剥夺，历史被后人所误读”。
- **人味化整改**：还原为中文传统意合与主动动词：“匈奴铁骑死死围住李陵；这一刀，生生剥碎了他的尊严；后人全把历史读偏了。”

### ❌ 4. 空洞的四字成语排比
- **AI 典型病句**：“波澜壮阔、催人奋进、荡气回肠、感人至深”。
- **人味化整改**：拒绝成语堆砌，还原为生理感官（冷汗、腥臭、颤抖、刀光）。

### ❌ 5. 滥用万能破折号制造假悬念
- **AI 典型病句**：“真相终于揭晓——他没有死——他选择了受刑”。
- **人味化整改**：减少“——”，用自然的标点或换行留白取代假停顿。

## 3. 过检检测器对抗（Perplexity & Burstiness 实操公式）

- **公式一：三字雷击法**
  在任何一段深入剖析（超过 60 字）的后面，必须强行截断，跟一个不超过 5 个字的单句。
  - *例*：“曹操要的从来不是美人，而是整个张绣军团的兵权。**他要立威。**”
- **公式二：口语括号补刀法**
  在陈述客观史实中间，用括号插入作者的主观吐槽或心理旁白。
  - *例*：“朱元璋把奏折往地上一砸（天知道那倒霉官员当时腿抖成什么样），冷笑着吐出两个字：推出去砍了。”
- **公式三：文白交叉重击法**
  引用古籍短语（4-8字），紧接现代通俗解构。
  - *例*：“史书上轻描淡写的一句‘老物可憎’，翻译成大白话，就是‘老不死的，看你一眼我都想吐’。”
